SkullBridge Forge 1.20.1 — full source project, NOT A COMPILED JAR

IMPORTANT: This project has not been compiled/tested here because Forge dependencies are unavailable offline.

1. Download official Forge 1.20.1 MDK from https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html
2. Extract these files FROM the official MDK into this folder: gradlew.bat, gradlew, and gradle/wrapper/ (keep the Gradle wrapper JAR and properties).
3. Install JDK 17.
4. Double-click BUILD_WINDOWS.bat with internet enabled. First build can take a while.
5. If successful, look at build/libs/skullbridge-1.20.1-1.0.0.jar. Upload it to your Forge server's mods folder and restart.
6. Run /skullbridge status as server OP. It shows online player count, average MSPT and Java memory.

Does NOT connect to Root yet or support console control. No secret token required.
